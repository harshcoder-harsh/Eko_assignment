# Minimal dependency set required to run the test suite.
#
# The full requirements.txt pulls torch + transformers + sentence-transformers
# (~1 GB), which the tests do not need: tests/conftest.py provides a
# `stub_embedder` fixture that replaces the SentenceTransformers model with a
# deterministic hash-based encoder. Installing only this subset keeps CI to
# roughly 30 seconds instead of several minutes.
#
# Versions are pinned to match requirements.txt exactly, so CI exercises the
# same versions the application runs against.
#
# NOTE: because this is a subset, CI does NOT prove that requirements.txt as a
# whole is installable. See the `deps` job in .github/workflows/ci.yml.
